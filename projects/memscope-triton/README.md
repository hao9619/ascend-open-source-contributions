# MemScope · Triton 采集支持

[返回合集](../../README.md) · [源码目录](source/) · [逐文件 SHA256](source-manifest.json)

## 工作内容

将Triton调用、参数地址、存储跨度和静态可能读写信息接入MemScope。支持启停、事件过滤、原有采集链共存及异常恢复；未知操作保守标记unknown。
