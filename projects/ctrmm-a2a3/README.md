# Complex TRMM · A2 / A3

[返回合集](../../README.md) · [源码目录](source/) · [逐文件 SHA256](source-manifest.json)

## 工作内容

实现复数三角矩阵乘法与Host接口，适配A2/A3。比较复数计算和归约策略，针对长归约失败输入修复数值误差，跟进编译、静态检查与官方测试反馈。
