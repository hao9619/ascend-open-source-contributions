## 工作内容

实现Sgetrf、Sgetri、SgetriBatched和SmatinvBatched。按矩阵阶数与批量选择计算路径，处理主元、奇异输入、工作区和布局；针对浮点运算顺序及近奇异矩阵开展精度诊断。
